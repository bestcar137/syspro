# 과제 1 — 전면처리, 후면처리 실습

## 실행 명령

```bash
sleep 100 &
sleep 100 &
jobs
ps -f
kill %1
ps -f
```

`&`를 붙이면 명령을 후면 (백그라운드)으로 실행한다. 쉘은 `sleep`의 종료를 기다리지 않고 다음 명령을 받는다. 반대로 `sleep 100`처럼 `&`가 없으면 전면 실행되어 100초 동안 기다린다.

## 명령별 결과 설명

| 명령                  | 결과와 의미                                                                                                                                           |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| 첫 번째 `sleep 100 &` | 100초 동안 대기하는 첫 후면 작업을 생성한다. 대화형 Bash는 작업 번호와 PID를 표시한다.                                                                |
| 두 번째 `sleep 100 &` | 첫 작업과 동시에 실행되는 두 번째 후면 작업을 생성한다.                                                                                               |
| `jobs`                | 현재 쉘이 관리하는 두 작업이 `Running` 상태로 나타난다. `%1`, `%2`는 이 쉘의 작업 번호이며 PID가 아니다. `+`는 현재 작업, `-`는 이전 작업을 표시한다. |
| `ps -f`               | 보통 같은 터미널의 쉘, 두 `sleep` 프로세스, `ps`가 보인다. PID는 프로세스 번호, PPID는 부모 프로세스 번호이다.                                        |
| `kill %1`             | 첫 작업의 프로세스 그룹에 기본 신호인 SIGTERM을 보내 종료를 요청한다.                                                                                 |
| 두 번째 `ps -f`       | 첫 `sleep`이 종료·회수된 뒤에는 두 번째 `sleep`만 남는다. 신호 직후 너무 빨리 조회하면 첫 프로세스가 잠시 보일 수도 있다.                             |

## 실제 실행 결과

종료 후에는 39313만 남았다. PID와 출력 순서는 실행할 때마다 달라진다.

`set -x`가 출력한 실행 명령이다.

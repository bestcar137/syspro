# 10장 과제 1, 2

강의 자료의 `malloc()`과 연결 리스트 예제를 바탕으로 작성했다.
과제 PDF 9~12쪽에 제시된 구조체와 함수 원형을 그대로 사용한다.

## 과제 1: 스택 (`hw01/stack.c`)

- `push()`는 리스트 맨 앞에 새 노드를 연결한다.
- `pop()`은 맨 앞 노드의 값을 반환하고 해당 노드를 `free()`한다.
- 마지막에 넣은 값부터 출력되는 후입선출(LIFO) 구조이다.
- `top`은 데이터를 저장하지 않는 더미 노드이고, `top.next`가 실제 맨 위 노드이다.

## 과제 2: 큐 (`hw02/queue.c`)

- `addq()`는 리스트 맨 뒤에 새 노드를 연결한다.
- `delete()`는 맨 앞 노드의 값을 반환하고 해당 노드를 `free()`한다.
- 먼저 넣은 값부터 출력되는 선입선출(FIFO) 구조이다.
- `head`, `tail`은 관리용 더미 노드이며 각각 `next`로 첫 노드와 마지막 노드를 가리킨다.
- 마지막 노드를 삭제하면 두 포인터가 모두 `NULL`이 되어 다시 삽입할 수 있다.

함수 인자가 단일 포인터이므로 호출자의 포인터 변수 자체를 바꾸는 대신,
더미 노드의 `next`를 바꾼다. 삽입과 삭제는 모두 O(1)이다.
빈 자료구조에서 삭제하면 오류 메시지와 `-1`을 반환한다.

## 입력과 종료

양의 정수(1 이상)를 공백 또는 줄바꿈으로 구분하여 입력한다.
0, 음수, 정수로 읽을 수 없는 문자 또는 EOF를 만나면 입력을 끝내고,
저장된 전체 데이터를 꺼내어 출력하면서 메모리를 해제한다.

PDF 10쪽 실행 화면과 동일하게 `%d` 입력을 사용했다.
따라서 `2.3`을 입력하면 정수 부분 `2`가 먼저 저장되고 다음 입력에서
`.`를 읽지 못해 종료된다. 실수 토큰 전체를 거부하는 방식은 아니다.
입력값은 C의 `int` 범위 내에서 사용한다.
